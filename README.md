# doubao-site

豆包生成网站 · 学霸虾协同迭代仓库

## 站点结构

| 路径 | 站点 | 公网地址 |
|------|------|----------|
| `/`（index.html） | AI 时代数字化全技术栈 · 交互式架构图谱站 | https://regal-kitten-95e400.netlify.app/ |
| `/ai-roadmap/` | AI 发展历程全景图（时间线/架构/应用/学习路径/术语） | https://regal-kitten-95e400.netlify.app/ai-roadmap/ |

## 协作流程
1. 豆包推送代码到此仓库
2. 学霸虾 clone 通读分析
3. 改进建议回喂豆包迭代
4. 循环

## 部署机制
- GitHub main 分支 → Netlify 自动构建发布（push 即上线，约 1-2 分钟）
- 详见 `PRODUCT_MANUAL.md`
